# ☕ Petal Pour Cafe - Modern Landing Page

A beautifully designed, fully responsive cafe landing page built with React.js and Tailwind CSS.

## 🎨 Features

- **Modern Design** — Clean and elegant UI
- **Responsive Layout** — Mobile-first design
- **Smooth Animations** — CSS animations and transitions
- **Multiple Sections** — Home, About, Menu, Gallery, Contact
- **Component Architecture** — Reusable React components
- **SEO Optimized** — Meta tags and semantic HTML

## 🛠️ Tech Stack

- React.js
- Tailwind CSS
- JavaScript (ES6+)
- HTML5

## 🚀 Quick Start

```bash
git clone https://github.com/Tanzim-sheikh/Petal-Pour-Cafe.git
cd Petal-Pour-Cafe
npm install
npm start
```
